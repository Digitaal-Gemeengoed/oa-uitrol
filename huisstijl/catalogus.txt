# Huisstijlen voor het inlogscherm en het paneel (vóór het inloggen).
# Kies er één met OA_HUISSTIJL in .env op VPS 1 en VPS 3; standaard voorbeeld.
# De server haalt het pakket zelf op van npm (met controle van de integriteit)
# en zet de CSS in huisstijl/huisstijl.css. Die staat niet in git: de huisstijl
# van een gemeente is van die gemeente (zie de licentie van het pakket).
#
# Een gemeente toevoegen: één regel, met het design-tokens-pakket van de
# gemeente uit NL Design System, de versie, het CSS-bestand in het pakket en
# de klasse waaronder de tokens staan.
#
# naam       klasse            pakket                                              versie   bestand
